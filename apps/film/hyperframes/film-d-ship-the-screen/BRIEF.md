## Intent

The developer film (`../STORY-DEV.md`), made the way B5 was: a story with a start, a middle and an
end; the docs' ideas made visual (quickstart, ui-documents, renderers, verifier, people-and-agents,
your-design-system, design-systems); hand-drawn doodles that arrive, point and leave; a camera that
works the code and the interface; captions that hold long enough to read twice; its own score.

## Rules kept

- Reading: every caption, key code line and note holds for at least words × 0.3 s + 1 s after it has
  finished appearing (captions at least 2.5 s). Code at 28 px or more on screen.
- Real: the screens are drawn by `@polyxd/web`'s browser build; the code is the docs' code; the
  terminal output is what the commands printed when run in this repository, trimmed.
- Only what exists today: no runtime SDK, no MCP server, no native renderers, no model of Polyxd's own.
- Score and sound effects from the HeyGen audio catalogue (the owner's signed-in account), frozen
  with `media-use resolve --from`; a different track from B5's and the Studio film's.
- Mix at −14 LUFS integrated, true peak at or under −1 dBTP.
